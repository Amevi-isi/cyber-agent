## 🔍 Analysis

### 1. Malicious Determination
> **⚠️ POTENTIALLY MALICIOUS**

The alert `ET SCAN Nmap` indicates **active network reconnaissance** originating from an **internal IP address** (`192.168.1.15`). This is suspicious because:
- Nmap scanning from an internal host suggests either a **compromised internal machine** or an **insider threat**
- Reconnaissance is typically the **first phase** of the cyber kill chain
- No prior events exist, but this could be the beginning of a larger attack sequence

---

### 2. 🎯 Attack Type
**Network Reconnaissance / Port Scanning**
- **Category:** Pre-Attack Reconnaissance
- **Tool Identified:** `Nmap` (Network Mapper)
- **Tactic (MITRE ATT&CK):** `TA0043 - Reconnaissance`
- **Technique:** `T1046 - Network Service Discovery`

---

### 3. 🚨 Severity: **MEDIUM**

**Rationale:**
- Internal source increases suspicion (lateral movement risk)
- Scanning alone is not immediately destructive
- Escalation potential is high if followed by exploitation attempts

---

## 📋 Recommended Actions
1. **Isolate** `192.168.1.15` for investigation
2. **Review** process/user activity on the source host
3. **Monitor** for follow-up alerts (exploitation, lateral movement)
4. **Check** if this host is authorized for security scanning (e.g., pentest activity)

### Reasoning

The combination of these two events forms a **clear attack pattern**:

2. **Event 2 - SSH Brute Force**: Following the scan, multiple failed SSH login attempts are detected on `server1` — consistent with an **automated brute-force attack** targeting discovered SSH services.

> ⚠️ This is a **classic Reconnaissance → Exploitation sequence** (MITRE ATT&CK).
